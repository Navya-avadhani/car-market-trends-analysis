# Car Market Trends Analysis

## About the Project

This is my first data analytics project, completed as part of the AICTE–VOIS for Tech Virtual Internship in Data Analytics.

The project explores a CarDekho used-car dataset using Python. It focuses on understanding the dataset, examining basic car-related information and exploring the distribution of different car names and fuel types.

## Project Objectives

- Understand the structure and contents of the dataset.
- Explore key numerical and categorical variables.
- Check for missing values.
- Examine the distribution of car names and fuel types.
- Present basic observations through visualisations.

## Dataset Overview

The dataset contains **301 records and 9 columns**, including:

- Car Name
- Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Previous Ownership

## Tools & Libraries

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

1. Imported the dataset and explored its initial records.
2. Examined descriptive statistics and dataset information.
3. Checked for missing values.
4. Analysed the frequency of different car names.
5. Explored fuel-type distribution using bar and pie charts.

## Key Observations

- The dataset contains 301 records across 9 columns.
- No missing values were identified in the dataset.
- Petrol vehicles account for the largest share of the records, followed by diesel and CNG vehicles.
- Honda City appears most frequently among the car names in this dataset.
